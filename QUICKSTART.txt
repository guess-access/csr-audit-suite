STEP-BY-STEP DEPLOYMENT (EASIEST METHOD)
================================================================================

1. EXTRACT THE ZIP
   - Unzip "csr-audit-suite.zip"
   - You should see these files:
     • index.html
     • audio-analyzer.html
     • audit-form.html
     • coaching-template.html
     • netlify.toml
     • README.md
     • DEPLOYMENT_GUIDE.md
     • FUNCTIONS_SETUP.md
     • netlify/functions/ (transcribe.js, analyze.js)

2. GO TO NETLIFY
   - Visit: https://app.netlify.com/drop
   - (No account needed yet)

3. DRAG & DROP
   - Drag the extracted folder (or individual files) onto the Netlify page
   - Wait 10-30 seconds for processing

   ⚠ IMPORTANT — AUDIO ANALYZER NEEDS A GIT OR CLI DEPLOY:
   Drag-and-drop publishes the HTML only; it does NOT bundle the
   netlify/functions folder, so the Audio Analyzer will not work on a
   drop deploy. To enable it, deploy from your GitHub repo (or with the
   Netlify CLI) and add the environment variable from
   FUNCTIONS_SETUP.md (GROQ_API_KEY - one free key covers
   transcription and scoring, no credit card needed).
   The Audit Form and Coaching Template work fine either way.

4. LIVE!
   - Netlify shows you a live URL
   - Click it - your site is live!
   - Share the URL with your team

EXAMPLE:
Your site might be at: https://admiring-bohr-12345.netlify.app/

COMMON QUESTIONS
================================================================================

Q: Do I need a Netlify account?
A: You'll need one to keep the site live. Free at netlify.com.

Q: Can audio files be seen or stored?
A: No. Audio is processed through secure API and not saved.

Q: How many people can use it at once?
A: Unlimited. It's a web app - everyone accesses simultaneously.

Q: Can I add a custom domain?
A: Yes! In Netlify Site Settings → Domain Management

Q: How much does it cost?
A: Netlify free tier is enough. $20+/month for advanced features.

Q: Can it work on mobile?
A: Yes! Fully responsive on phones, tablets, desktops.

Q: What if audio upload doesn't work?
A: Ensure file is MP3 (not WAV), under 10MB, try Chrome browser.

Q: Can agents log in separately?
A: Default is open access. You can add authentication if needed.
